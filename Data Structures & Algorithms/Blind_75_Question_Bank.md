# Blind 75 — Question Bank

> **Format:** A curated practice list, not worked solutions — the specific, widely-known "Blind 75" selection (originally compiled and circulated by a former Facebook engineer as a minimal, high-leverage problem set for coding interview prep), organized here by data-structure category the way the list is traditionally presented, rather than by algorithmic pattern. Pair this with the [DSA Pattern-Based Question Bank](DSA_Pattern_Based_Question_Bank.md) for pattern-recognition practice, and with [Computer Science Fundamentals](../Computer%20Science%20Fundamentals/Computer_Science_Fundamentals_Interview_Prep.md) for the underlying Big-O/data-structure concepts. **Target level:** Basic (fundamentals) → Staff (efficient, correct solutions under time pressure). **Last verified:** 2026-08-25.

**Two notes on this list before you use it:**

1. **Provenance and precision.** "Blind 75" has been reproduced, mirrored, and slightly modified across hundreds of blogs, GitHub repos, and videos since it first circulated in 2018 — this guide's version could not be cross-checked against a single authoritative source (the two most likely canonical pages both refused automated verification, the same bot-blocking pattern already documented for `leetcode.com` in this repo), so treat this as a high-confidence reconstruction of the commonly-cited list, not a guaranteed-exact reproduction. If a specific problem here doesn't match another copy of "Blind 75" you've seen, that's expected — the core ~70 problems are consistent across essentially every version; a handful of premium-locked problems (marked below) are the ones most likely to vary by source.
2. **LeetCode links.** Exactly as in the pattern-based question bank, `leetcode.com` blocks all automated link-checking, so these links are generated mechanically from each problem's well-known title and were not individually confirmed live. Search by title on leetcode.com if one seems off. A few problems below are marked **(premium)** — they're LeetCode Premium-only and the link will require a paid account to actually open.
